# SKY SEND

SKY SEND — учебный сервис рассылок на Django. Позволяет создавать клиентов, сообщения и рассылки, управлять отправкой и правами пользователей (менеджеры, суперпользователи и обычные пользователи).

## Стек технологий

- Python 3.13
- Django 4.2
- Poetry (управление зависимостями)
- Bootstrap 5 (оформление интерфейса)
- SQLite (по умолчанию)

## Возможности

- Регистрация и авторизация пользователей
- Разделение ролей: суперюзер, менеджер, обычный пользователь
- Список клиентов (получателей рассылок), CRUD‑операции
- Список сообщений, CRUD‑операции
- Список рассылок, детальный просмотр, создание/редактирование/удаление
- Ручной запуск рассылки («Запустить сейчас»)
- Отключение рассылки («Отключить рассылку»)
- Просмотр логов отправки
- Список пользователей сервиса для менеджера/суперпользователя, блокировка/разблокировка

## Установка и запуск

```bash
# Клонировать репозиторий
git clone <URL-репозитория>
cd sky_send

# Установить зависимости через Poetry
poetry install

# Выполнить миграции
poetry run python manage.py migrate

# Создать суперпользователя
poetry run python manage.py createsuperuser

# Запустить дев-сервер
poetry run python manage.py runserver
```

После запуска приложение будет доступно по адресу http://127.0.0.1:8000/.

## Основные URL

### Клиенты и сообщения

- `/clients/` — список клиентов
- `/clients/<id>/` — детальная карточка клиента
- `/clients/create/` — создание клиента
- `/messages/` — список сообщений
- `/messages/<id>/` — детальное сообщение
- `/messages/create/` — создание сообщения

### Рассылки

- `/mailings/` — список рассылок
- `/mailings/<id>/` — детальная страница рассылки
- `/mailings/create/` — создание рассылки
- `/mailings/<id>/edit/` — редактирование
- `/mailings/<id>/delete/` — удаление
- `/mailings/<id>/send-now/` — ручной запуск
- `/mailings/<id>/disable/` — отключение рассылки

### Пользователи

- `/users/login/` — вход
- `/users/logout/` — выход
- `/users/register/` — регистрация
- `/users/list/` — список пользователей (только суперюзер и менеджер)
- `/users/block/<id>/` — блокировка/разблокировка пользователя

## Роли и доступ

- **Суперпользователь**:
  - Полный доступ ко всем разделам
  - Видит все клиентов, сообщения и рассылки
  - Видит меню «Пользователи» и может блокировать пользователей
- **Менеджер** (пользователь в группе `manager`):
  - Имеет такие же права, как суперюзер, кроме административной части Django
- **Обычный пользователь**:
  - Видит только свои клиентов, сообщения и рассылки
  - Не имеет доступа к списку пользователей и управлению чужими рассылками

## Кеширование

Для повышения производительности настроено:

- серверное кеширование отдельных списков (`ListView`) с помощью `cache_page`
- осторожное использование кеша, без кеширования страниц с пользовательским контекстом (меню, логин/логаут)

При изменении логики кеширования важно не кешировать страницы, где выводится текущий пользователь или его права.

## Тесты и качество кода

- Проверка стиля: `flake8 .`
- Базовые настройки соблюдают PEP8, длинные строки в миграциях при необходимости разбиваются или помечаются `# noqa: E501`.
